The frame budget is the spec
Keystroke to glyph is bounded work: a rope edit and a repaint of visible rows. No full-file scan, no reparse, no disk touch. Frame time stays on screen, next to the budget it has to beat.
5
Five position types, zero bare integers
ByteOffset, CharOffset, Point, DisplayPoint, Anchor — distinct types with explicit, tested conversions. Editors are bug factories because “position” is ambiguous. Here it never is, and the editor shows you all of them at once.
1
One vocabulary: everything is an Action
Keymaps resolve to Actions. The palette lists them, macros record them, dot-repeat replays them, tests drive them headless. Composability stops being special cases and becomes a grammar.
Vim's grammar.
A selection set underneath.
A cursor is a one-wide selection with a primary. Every operator maps over the set, so multi-cursor is never a special case — and tree-sitter makes structural objects nearly free.

What vex will not do
No plugin system, no remote editing, no debugger UI, no collaboration, no settings GUI, no Windows or macOS build in v1. Deferring the extension API is what keeps the rest honest — it is the thing that makes other editors enormous, and it constrains every internal API the moment it exists.
Success has one criterion
Not feature parity — daily use. From M3 onward vex is written inside vex, and its own bug tracker is the friction of using it. Four to six months of steady part-time work to a genuine daily driver.
