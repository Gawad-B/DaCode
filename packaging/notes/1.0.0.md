DaCode 1.0.0: the editor under its new name, with a new interface, a new logo and twelve themes.

DaCode is a vibe-coded project. The code was written with AI; the architecture, the design system
and the designs of the editor and its landing page were chosen by its author. It was made for
personal use and is published so that anyone who wants to can try it.

## What is new

- **A new interface**, shaped like VSCode and Zed: a menu bar, an icon column that switches the
  sidebar, a file explorer, tabs, and a status bar. Every button shows its name and its shortcut.
- **A new logo and name**: ضَ, the Arabic letter ḍād read "Ḍa" — the first syllable of DaCode.
- **Settings as a tab**, with pages, search, and changes saved as you make them.
- **Twelve themes**, each named for its palette: Slate (the default), Walnut, Rosé Pine, Rosé Pine
  Moon, True black, Espresso, Charcoal coral and Abyss; Linen, Cream, Mist coral and Snow. Pick one
  from a list split into Dark and Light. Old theme names in `init.lua` still work.
- **Movement**: panels and popups spring into place, and the touchpad scrolls by pixels. Both can be
  reduced or turned off.
- **One font**: everything is set in Fira Code.
- **The keys follow the click**: click the file tree and the arrows move in the tree; click the code
  and they move the caret.
- **Search and replace across the project**, in the sidebar as in VSCode: `ctrl-shift-f` opens a
  query box with match-case, whole-word and regex toggles, a replacement box, and the results
  grouped by file. Replace all asks to be pressed twice, since it rewrites files.

## Fixed

- Syntax colours appear as soon as a file opens, without a key press.
- A diagnostic's message is written at the end of its own line instead of in a box that hid the
  next one, and it no longer shows over the settings tab.
- A row behind the open theme list no longer lights up under the pointer.
- The problems list shows the file you are in, not every file the language server ever reported.
- Opening a folder closes the old folder's files (unsaved ones stay), with no `untitled` tab left
  behind and no message box over the code.
- Up and down keep their column instead of dropping to the start of the line after a blank one; at
  the end of a line, the caret stays at line ends.
- Sticky scroll, which looked like a highlighted band at the top of the code, is off by default.
- The run-and-debug view, which only showed the editor's internals, is gone.

The full list is in `CHANGELOG.md`.
