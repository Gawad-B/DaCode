Two halves: the features 0.3.0 left half-built, and an adversarial review of everything behind them.

## New

**Find and replace** in the open buffer. **Alt-drag** for rectangular selection. **Horizontal
scrolling**, with one definition of where a column is in pixels that the drawing and the mouse both
read.

**Tabs you can close**, file create/rename/delete from the tree, and crash recovery for *every* dirty
buffer rather than only the one on screen. The problems panel keeps every file's diagnostics.

**Language servers** can be named from `init.lua`. Completion uses what the server actually sent,
including auto-import — which turned out to be a *handshake* gap rather than a parsing one, since
rust-analyzer withholds out-of-scope candidates entirely unless the client advertises
`resolveSupport`. Go-to-symbol in the file or across the project. **Formatting works with no server
at all**, through a worker that runs ruff, black, prettier and the rest.

**Git**: walk the gutter hunk by hunk and revert one change at a time.

## Fixed

Thirty-three defects confirmed by two adversarial review passes. Three could lose work:

- **Typing in the search box could kill the editor.** Case-folding `İxÅ` keeps the same total byte
  length while moving every offset inside it, so searching that line sliced mid-character and
  panicked on the UI thread — taking every unsaved buffer with it.
- **A crash lost the unsaved work in every file but one.** Recovery copies were written for all dirty
  buffers, but session restore never looked one up, and the first save then deleted it.
- **`d5G` deleted to the end of the file** instead of to line five.

And, among the rest: folds never moved when the text under them did, so a delete above a closed fold
could hide the rest of the file; clicks landed up to three lines low wherever sticky scroll had
pinned a heading; typing `}` walked to the start of the document at 5.8 ms per keystroke; one file
opened two ways became two buffers with separate undo histories; and `x/../../../../evil.txt` passed
the "is this inside the project?" check.

**724 tests, clippy clean.** Every regression test was verified by putting the defect back and
watching it fail — which caught three tests that were checking nothing.
