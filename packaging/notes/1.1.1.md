DaCode 1.1.1: language servers that install themselves, images and PDFs in a tab, and zoom.

If you have 1.1.0, DaCode offers this release itself — the bell says **Restart now**. From 1.0.0 or
earlier, install it by hand once; every release after that arrives on its own.

## What is new

- **Language servers and formatters, with nothing to install first.** Open a Python file and run
  **install a language server** from the palette (`ctrl-shift-p`), or click the missing row on the
  Languages page of Settings: DaCode downloads pyright and ruff for your machine, checks them, and
  starts the server. The same goes for rust-analyzer, clangd, lua-language-server and stylua, the
  TypeScript server and prettier. From a terminal: `dacode tools install pyright ruff`, and
  `dacode tools list` for the rest. Every download is checked against a SHA-256 built into DaCode;
  the npm-based tools run on a copy of Node DaCode keeps for them. Anything you installed yourself
  is still used first.
- **Images, PDFs and office documents open in a tab.** Zoom with `+` `-` and `ctrl`+wheel, `0` to
  fit; PDFs scroll page by page. Word, Excel and PowerPoint files show their text and tables, read
  only. A viewed tab can never be saved over the file.
- **Zoom everything** with `ctrl-=`, `ctrl--`, `ctrl-0`, kept between sessions. The new
  **Accessibility** page in Settings has it with the font size and animations.
- **Rainbow CSV**: a colour per column, and the column's name on the status line.

## Changed

- **▶ Run runs the file you have open**, with `python3`, `node`, `go run` or a compiler, and still
  runs the project for a file that belongs to it.
- The terminal folds to its tab strip while Settings is in front.

## Fixed

- Closing a terminal tab could leave its shell running until DaCode quit.
