DaCode 1.2.0: DaCode on the Mac, signature help, Emmet, bracket colours and a minimap.

If you have 1.1.0 or 1.1.1, DaCode offers this release itself: the bell says **Restart now**. From
1.0.0 or earlier, install it by hand once; every release after that arrives on its own.

## What is new

- **macOS.** One app for Apple Silicon and Intel Macs, macOS 11 or later, as a `.dmg` to drag into
  Applications. ⌘ does what Ctrl does everywhere else, and every menu and tooltip prints keys the
  Mac way (⇧⌘P). The left Option key is Alt and the right one still types `@` and `{`, which
  Settings can change. Open With in the Finder and a drop on the Dock open files and folders, and
  language servers installed with Homebrew, nvm or pyenv are found even when DaCode is started from
  the Dock. It updates itself like the other builds. **It is not signed with an Apple Developer ID**,
  so the first launch is a right-click → Open, and **nobody has used it on a real Mac yet**: it is
  built and tested in CI, and the first reports will find things.
- **Signature help.** Type `(` or `,` in a call and its signature appears above the line, with the
  argument you are on lit. `ctrl-shift-space` brings it back.
- **Emmet** in HTML and CSS: type `ul>li*3` or `m10`, press `ctrl-space`, accept. Download it with
  `dacode tools install emmet-language-server`, or from the Languages page of Settings.
- **Bracket colours.** Each pair of brackets in the colour of its depth, read from the syntax tree
  so brackets in strings and comments are left alone. On by default.
- **A minimap**, off by default: Settings → Editor → Minimap. Click or drag it to scroll.

## Fixed

- **Sticky scroll could cost 57 ms a frame** far down a very large file, because it walked up to
  the first line looking for the block you were in. It now looks 500 lines up.
