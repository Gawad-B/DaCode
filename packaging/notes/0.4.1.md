Everything here came from one person installing 0.4.0 and using it for an afternoon, which found more
than two rounds of adversarial review had.

## Fixed

**Escape put you into a mode you could not leave.** With Vim keys off there is one mode, but Escape
resolved to "collapse selections", which set normal mode unconditionally — so the key every editor
uses for "never mind" gave a blue block cursor and a blue gutter while the statusline went on saying
EDITING. Nothing in the non-modal keymap could type the `i` that would have got you out.

**The Linux icon was invisible rather than missing.** The desktop entry and all nine icon files were
correct; the art was a near-white chevron on transparency, on the reasoning that docks are usually
dark. On a light application menu that is not a faint icon, it is a blank tile labelled "vex". The
icon now carries the editor's own background, so it reads on any panel. The rpm and deb also refresh
the icon cache, which neither did — an entry missing from that cache falls back to the same blank
tile.

**The toolbar ran SETTINGS into COMMANDS on Windows.** Button widths came from a constant of 7.5
pixels per character, below the editor's own estimate for the type it draws them in and tied to
nothing, so it could not follow the font size either. Linux resolves narrower fonts and hid it.

**Nothing but the file scrolled.** The mouse wheel had no idea what was on screen: the settings
panel, the key list, the command palette, the file tree, the search results and the problems list all
ignored it while the file behind them scrolled instead.

**A message stopped mid-word and then would not go away.** The box split only on hard newlines, so a
one-paragraph message was one line however long, clipped where the rectangle ended with no ellipsis —
you were told the beginning of why something failed and left believing that was all of it. It also
sat there until Escape, so "opened a folder" was still on screen three files later.

## New

**Install a language server without leaving the editor.** vex has no marketplace, and the answer to
"no Python language server" used to be a line to go and type somewhere else. It now runs that same
line for you: rust-analyzer through rustup, the TypeScript and pyright servers through npm,
basedpyright and pylsp through uv, pipx or pip — whichever your machine actually has, since bare
`pip install` is refused outright on most Linux distributions.

It never runs a shell, never asks for root, and refuses once before doing anything: the first request
prints the exact command, the second runs it. clangd, lua-language-server and the Dart SDK keep
advice instead of a button, because no single command is honest for them and an editor offering a
button that cannot work is worse than one that says what to type.

"The installer exited zero" is not treated as success — on Windows both pip and `go install` write to
directories PATH does not cover — so it looks for the program afterwards and says so if it is still
not there.

## Still true

Nobody has run vex on macOS. The Windows window, mouse and folder chooser had never been used by
anyone before 0.4.0, and half of this release is what that found.

Buffer search is still linear in the document, and opening a file is still synchronous. Both are
bounded, and both say so.
